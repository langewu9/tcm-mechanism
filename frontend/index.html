支持百炼 Qwen 与本地 QLUNLP/BianCang-Qwen2.5-7B-Instruct。只要本地服务提供 /v1/chat/completions，AI Scientist 就能复用同一套接口。

百炼：
set DASHSCOPE_API_KEY=你的百炼APIKey
set QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
set QWEN_MODEL=qwen-plus
start_web.bat

本地 BianCang：
set QWEN_BASE_URL=http://127.0.0.1:8000/v1
set QWEN_MODEL=QLUNLP/BianCang-Qwen2.5-7B-Instruct
start_web.bat
点击“测试连接”后显示模型响应。

部署方式

Web + API + PyQt 桌面入口

本平台为 FastAPI 后端加静态前端。开发环境可直接运行 Uvicorn，生产环境可放在 Windows 服务、Nginx 反向代理或校园服务器中。

cd /d D:\MMDD\tcm_pharmacology_platform
D:\mini\envs\py310\python.exe -m uvicorn backend.main:app --host 0.0.0.0 --port 8010

接口文档地址：/docs。优化版 PyQt 可运行 start_desktop.bat 打开。
