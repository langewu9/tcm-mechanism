# Scroll-only brush script

Zhi Mang Xing, Copyright 2018 The Zhi Mang Xing Project Authors.
Official source: https://github.com/google/fonts/tree/main/ofl/zhimangxing
License: SIL Open Font License 1.1, included as OFL.txt.

`scroll-script.woff` is a WOFF subset of ZhiMangXing-Regular.ttf generated
with fontTools. Name/copyright metadata are retained. CSS family alias:
`YuanzhiScrollScript`. Subset characters: 远志求本智药存档

Only `.hero-scroll-title` and `.hero-scroll-caption` use this typeface.
Homepage headings, branding, module names, body, controls and R charts
keep the professional UI font. The font is served locally, without a CDN.
