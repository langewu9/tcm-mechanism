# Homepage brush type

Source: Ma Shan Zheng by the Ma Shan Zheng Project Authors.
Official source: https://github.com/google/fonts/tree/main/ofl/mashanzheng
License: SIL Open Font License 1.1; full license in OFL.txt.

`yuanzhi-brush.woff` is a WOFF subset generated with fontTools from the
official MaShanZheng-Regular.ttf. Copyright and name metadata are retained.
It contains the fixed Chinese homepage headings and scroll inscriptions,
not arbitrary research content. The CSS family alias is `YuanzhiBrush`.
Controls, body text, numeric data and R charts deliberately retain their
existing readable UI font. No font CDN is required at runtime.

Subset text (update the subset when changing display copy):
