## 更新后需要注意

1. 更新依赖和环境后，先备份正式数据库，执行 `python manage.py migrate`。本轮包含 `0023_retain_research_records` 和 `0024_retain_case_audit_actors` 两个迁移，用于归档字段及保护溯源关系；详细规则见 [研究资料保留](research-retention.md)。
2. 重启 Django、Celery worker 和 R，使代码与绘图器版本生效。新规则不会自动重算历史分析或覆盖历史图表。
3. 旧 UniProt 预览需重新生成后才能应用；来源文件或本地身份依据变化也要重新预览。定时同步总开关仍由部署配置控制。
4. Git 只保留源码、测试、迁移和说明。`.env`、凭据、模型、原始工作簿、研究上传、数据库和私有图表没有上传。公共合成图库 `public/r-demo/` 是忽略的构建产物；其他电脑需按 [R 使用说明](../r_viz/README.md) 运行 `r_viz/prepare_demo_gallery.py`，再执行 `pnpm --dir web build:delivery`。
