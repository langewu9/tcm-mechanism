## 疾病汇总复刻与计数口径

`GET /api/v1/catalog/diseases/evidence-search/` 复用 main 的 51 组精确疾病别名，在已导入、启用来源的疾病目录中检索。返回疾病—中药、疾病—靶点、疾病—中药—靶点三类活动证据；直接三元关系的中药只接受可信 `herbStableId`，不按显示名称补造。JSON 同义词字典的键不作为名称匹配，错误键命中也不会占满前 20 项匹配窗口。

结果最多 20 个疾病匹配和 1,200 条关系，计数与导出都只包含本次返回范围，截断时明确提示。多个疾病命中不自动合并；没有匹配与匹配到疾病但没有关系分别显示。接口只读取共享知识目录，不读取研究者私有医案/上传内容，也不创建任务、同步或医案审计记录；身份与统一错误格式沿用 Django。

`test_disease_evidence.py` 用固定合成旧表输入分别建立 SQLite 与 Django 关系，实际执行 main 的 `search_disease` 原函数，比较疾病/中药/靶点三元行和名称集合。原 `backend/data_service.py` 的 SHA-256 固定为 `7fae7384a64b236d787696fbe1288c583d680df59054e8592cd93f60897aa6f9`，已核对与 `origin/main@078d374` 一致；旧预期结果不从新接口输出生成。

该样例验证可比字段，不代表旧接口与新接口所有计数相等：main 的中药/靶点按名称去重，旧 `links` 仅含三元表；新接口按实体 ID 计数，`links` 同时包含三类关系，并逐条保留来源版本。固定样例旧三元记录为 2 条，新返回 6 条关系，其中三元关系仍为 2 条；两个同名中药/靶点保持独立身份。main 中文别名逐项查找可能重复拼接同一证据，新接口同一关系只返回一次。

## 仍需区分的结果差异

- 当前网络检索按规范名称/同义词精确匹配、按实体 ID 求交集；main 旧数据查询使用模糊名称，交集按规范化名称。相似名称、同名不同实体的结果可能不同。
- 同数量图表按名称/ID 稳定排序，main 保留原数据顺序；来源对象、数组字段及任务元数据按当前可追溯契约返回。
- 疾病汇总使用迁移后的版本化知识目录，名称身份、关系范围、数量上限与旧 SQLite 汇总不同，详见上述计数口径；不能将新增来源表格称为逐像素相同的旧结果正文。
- Reactome 使用实际来源版本，main 写死版本；旧全局历史富集表未迁入，页面标“未迁入”，不读取其他研究者私有任务。
- 文本规则无命中或目录缺失时不取第一条记录回退；蛋白组学排除无效数字并保留 QC。这些为数据正确性修正，不能宣称与旧版所有输入的输出完全相同。
- main 真实 Excel/SQLite 数据、代表性医案与蛋白组学输出没有随仓库交付；真实模型、PostgreSQL、R 容器和公网部署仍待验收。

## 验证记录

最新本地代码的 246 项 Django 全量自动化测试通过（含 8 项疾病证据测试），系统检查、无待生成迁移检查、无警告 OpenAPI 校验，以及 TypeScript/Vite 构建通过。Vite 仍提示单个 JS chunk 超过 500kB，构建成功；加载性能优化未作为本轮复刻修改。前一轮静态 React 渲染核验了单个共享顶栏、桌面/移动导航数量、唯一选中管理入口、八个研究标签和面板、分析布局，以及默认/长 SVG 标签的无障碍全文；该检查不覆盖浏览器样式和点击交互。

本轮在独立合成 SQLite 库运行 6 组 Django Client 联调，经过实际 CSRF/session 中间件，核对未登录/退出后拒绝、登录保护、疾病汇总/来源/同名身份、统一输入错误、无匹配/无证据/截断、总览所有者隔离和旧 alias-search 入口。捕获的疾病读取为 5 条 SELECT，所有模型表计数保持不变。再将实际接口响应交给 React 静态渲染，5 组检查覆盖总览原布局/五项任务/业务路由、加载与错误空态、疾病来源及导出入口、空结果和截断、八个标签、HTML 转义及 CSV 公式防护。静态渲染通过临时适配注入加载/错误状态，不模拟实际浏览器请求或点击；未改正式数据库。

前一轮独立临时 SQLite 库通过实际 Django 服务和构建后的前端静态服务完成 12 项 HTTP 联调：登录前拒绝、CSRF 登录与姓名/邮箱、个人总览、网络黄金统计及直接中药字段、中药证据、疾病别名、成分对照、文本分析及 CSV/PDF、管理员拒绝、原路径入口、PNG 原样提供、退出后私有 API 再次拒绝。所有写入为合成测试数据，未写入正式数据库、未调用外部模型。

HTTP 联调验证接口和静态资源连接；尚未验证浏览器实际渲染与点击交互，更不替代真实研究数据的结果对照。
