## 本轮修正的网络结果

新任务保存统计版本 `main-078d374-candidate-statistics-v1`；历史任务不重新计算。

| 项目 | 修正后的行为 |
|---|---|
| 直接关联数量 | 包含同时属于严格交集的直接关联靶点；候选并集去重，同一候选优先标为严格交集 |
| 成分图 | 只计候选靶点范围，排除零候选成分 |
| 通路数与通路图 | 只统计候选靶点的真实通路；直接关联独有候选也读取启用、版本化通路证据 |
| 候选中药字段 | 合并成分链中药与可信 `herbStableId` 指向的已选规范中药，不按 `herbLabel` 猜测归属 |
| 来源 | 候选、通路和任务继续保留实际来源版本及关系记录号 |

黄金输入/输出在 `python_app/apps/core/tests/fixtures/main_network_statistics.json`，记录 main 完整提交及原 route 文件 SHA-256。预期结果由 main 原 helpers 和统计代码在 Node 执行得到，Python 测试以等价证据对照；独立审查重跑确认。合成样例含重复关系、交集/直接关联重叠、非候选成分和通路。边界检查覆盖同名实体身份、停用来源、排序、截断、可信 stable ID 和误标中药标签。

## 仍需区分的结果差异

- 当前网络检索按规范名称/同义词精确匹配、按实体 ID 求交集；main 旧数据查询使用模糊名称，交集按规范化名称。相似名称、同名不同实体的结果可能不同。
- 同数量图表按名称/ID 稳定排序，main 保留原数据顺序；来源对象、数组字段及任务元数据按当前可追溯契约返回。
- 疾病标签目前展示疾病别名目录和实体关系，不等同于旧疾病查询汇总视图。
- Reactome 使用实际来源版本，main 写死版本；旧全局历史富集表未迁入，页面标“未迁入”，不读取其他研究者私有任务。
- 文本规则无命中或目录缺失时不取第一条记录回退；蛋白组学排除无效数字并保留 QC。这些为数据正确性修正，不能宣称与旧版所有输入的输出完全相同。
- main 真实 Excel/SQLite 数据、代表性医案与蛋白组学输出没有随仓库交付；真实模型、PostgreSQL、R 容器和公网部署仍待验收。
