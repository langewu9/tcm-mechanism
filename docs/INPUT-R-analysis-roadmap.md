# INPUT 参考功能与 R 分析实施目录

核查日期：2026-10-10。参考 https://cbcb.cdutcm.edu.cn/INPUT/Help/ 与 /Enrichment/（通过浏览器实际查看）；Browse 提供疾病、基因、中药、成分四类实体目录。

## 可实现目录

| 参考功能 | 本项目实现 | 必需数据 / 边界 |
| --- | --- | --- |
| Herb–Ingredient–Gene–Disease network | R 分层证据网络，四格式导出 | 本地来源可追溯的节点与关系，不从名称推测互作 |
| PPI network / confidence score | STRING 物理互作 R 网络，查询阈值沿用原输入 | 必须先单独同意发送标识，成功返回互作；不把通路共现当 PPI |
| Gene distribution | 基因—通路网络、每通路唯一基因数量图 | 本地实际基因—通路关联；计数不等于富集显著性 |
| GO BP / CC / MF, KEGG | 已有 g:Profiler 气泡图 + 分类条形图 | 查询集和测量背景；FDR≤0.05；注明来源和版本 |
| Data Query / Browse | 保留网站的实体检索、来源和证据表 | 不将数据库查询塞进无数据库凭证的 R 服务 |
| Statistics / downloads | 分析概览、连接度排行、SVG/PDF/PNG/HTML | 统计仅描述当前返回的有界图；不宣称因果或生物学核心性 |
| 本项目补充 | Reactome 富集气泡图、差异蛋白火山图 | 分别标注 Reactome / 差异分析统计来源 |

## 实施阶段与验收

1. 新增有界 Python 图表适配、R 网络/条形/气泡绘制和统一网页入口；保留父任务、权限、输入/输出哈希、来源 release 和私有下载。无数据按钮显示原因，不生成演示边填充真实结果。
2. 单元测试覆盖 PPI 状态、阈值、有限数值、孤立点、去重、端点完整、源任务隔离、请求大小与空结果。前端构建与现有回归测试通过后，用明确标记的合成 fixture 实测真实 R 四种产物。
3. 新功能提交到协作 PR 分支，不直接覆盖 main；仅源码、测试和文档入库。数据库、用户上传、模型、令牌和生成图表不提交。
4. 后续独立阶段：R clusterProfiler 本地 ORA / GSEA、版本固定的 GO/KEGG 注释快照与许可核对；原始矩阵 PCA / 相关性 / 热图仅接收经授权的去标识统计摘要。当前 g:Profiler 是外部 ORA，不称为 clusterProfiler；差异表不包含样本重复，不能生成真实 PCA。
5. 更大网络的交互布局、社区检测、中心性与模块富集须单独确定算法、截断策略和可重现参数。首期是静态网络与可下载 HTML 数据表，不宣称与 INPUT 所有算法等价。

## 安全与科学边界

- R 仅接收绘图必需的标签、统计及关系摘要，不接收原始文件、医案正文、账号、凭证或数据库连接。
- PPI 原始边来自已同意的 STRING 查询；无成功结果时禁止生成 PPI。置信度是证据评分，不是 P 值或因果概率。
- 网络按完整有效输入图的连接度排序选取最多 80 个节点、500 条边，子图保留唯一无向边及有效端点；标题说明输入与展示数量。SVG 节点大小按展示子图连接度，连接度排行按完整有效返回图计算，两者明确区分。
- R 请求 ≤1 MiB；任何图均要求已完成父任务；生成失败不修改父分析结果。四种产物通过所有者权限下载。
- GitHub 同步仅表示协作代码发布，不等同于公网网站部署验收。Docker Python 镜像下载当前受网络限制，本机使用 Windows solo worker 作为临时预览。

## 首期验收记录

2026-10-10：七类新增图表已通过本机 R 0.2.0 的真实 HTTP 接口生成 SVG/PDF/PNG/HTML（28 份产物），验收输入明确标记为 SYNTHETIC，不写入应用研究任务或知识库。另通过网页操作验证现有合成差异分析任务的 R 概览排队、绘制和私有下载链路。缺少 STRING/本地通路结果时，相关按钮停用。

- 321 项 Django 回归测试通过；全套采用独立测试进程的快速 MD5 测试哈希以缩短造用户时间，网站运行配置与账号密码未改变。新增/原有绘图的 22 项测试亦在默认哈希设置下通过。
- 10 组离线前端测试、TypeScript 与 Vite 生产构建通过；CI 已增加 `test:r`。
- 实机 R 验证包括未授权请求、缺失端点、重复节点的拒绝处理；PNG 核对中文、节点类型、连接度与图例。
- 未做外部 STRING / g:Profiler / Reactome 的真实科研查询验收，也未把合成 PPI 边当作数据库证据。clusterProfiler、本地 GO/KEGG 快照、PCA/热图和交互网络尚未完成。
