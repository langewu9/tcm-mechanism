# 界面字体规范

更新：2026-10-14。

- 主字体：Microsoft YaHei（微软雅黑）；按系统回退 PingFang SC、Noto Sans CJK SC、Noto Sans SC、system-ui、sans-serif。页面及 R HTML/echarts4r 使用同一字体栈，不依赖外部字体下载。
- 标题/强调：600；正文/表单内容：400；按钮/导航：500。数字区域采用 tabular-nums，便于表格对齐。代码、JSON 与校验值使用等宽字体。
- 字体唯一入口为 web/src/styles/typography.css，必须在历史主题样式之后引入。旧宋体、楷体、手写体及 Google Fonts 导入已移除；品牌图片不改动。
- 既有配色、图表完整高度及交互布局保留。16 个合成演示和 7 个公开示例的 HTML 控件/图表字体已刷新，原始输入数据和静态图不重写。
- R 新渲染版本为 r-viz-0.4.1；历史用户产物保持原版本。Windows 静态 R 图使用 Microsoft YaHei，Linux 使用 Noto Sans CJK SC。
