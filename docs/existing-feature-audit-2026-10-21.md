## 复现问题与处理

| 问题 | 触发与影响 | 修补结果 |
| --- | --- | --- |
| 蛋白组学任务恢复只查混合列表第一页 | 较新的其他类型任务占满一页后，已保存的蛋白组学任务消失 | 使用现有类型筛选查询最新蛋白组学摘要，再按其编号读取详情 |
| 图表历史只查第一页 | 多次绘图或较多其他图表会把所需火山图/气泡图挤到后页 | 按持久父任务筛选，逐页寻找所需图表；只读取实际展示的最新详情，不跟随响应中的任意 URL |
| 可分析数据集只有第一页 | 研究者拥有多页数据集时，较早的文件无法从分析页选取 | 原选择框配套上一页/下一页，按页读取，失败可重读或返回上一页；不一次加载全量资料 |
| 进度读取失败后永久停止 | 蛋白组学和 R 目录一次网络错误后，不再轮询，界面停在执行中 | 有上限的退避间隔自动重读，验证任务身份；只重读原任务，不创建新分析或重新绘图 |
| 快速重复提交 | 页面尚未重新渲染时，蛋白组学、证候分析或 R 绘图可接受两次提交 | 增加同步提交锁；已排队/执行或已完成的图表继续沿用现有任务规则 |
| 新分析残留上一任务火山图 | 开始另一分析时只清除了气泡图，旧火山图可能留在新结果旁 | 清除两类旧图表和逐行分页状态；新响应核对任务类型、数据集及图表父任务/类型 |
| 辅助读取失败遮蔽有效结果 | 数据集列表或图表历史出错时，其他已保存结果也无法恢复 | 分开处理列表、分析和图表读取；保留已核实结果，并提供只读重试 |
| QC 页码与表格不一致 | 切换页码后，新数据返回前仍展示旧页行 | 切页立即清空旧行；失败明确提示并可重新读取当前页，不把旧行标成新页 |
| 证候历史读取失败被写成空记录 | 后端暂时不可读时，页面显示“暂无保存结果”；创建成功后的历史刷新失败也混入创建错误 | 历史错误单独展示；新结果保存后保留；重试只读取历史，不重新创建任务 |

另补充了页面卸载后的响应隔离、重复导出保护，以及外部分析勾选状态在提交后清除。读取历史不会恢复外部同意，也不重新发起外部请求。

图表恢复只认已保存的父任务关联。未绑定父任务的旧图表仍保存在原任务/存储中，不补造父子关系、不重算历史结果。

## 仍保留的缺口

1. 旧 AI Scientist 专用监测分支仍返回未迁移状态（501），不能把现有科研助手当成该旧流程已经复刻。须单独核对原方法及实际所需数据，本轮不写替代算法。
2. Reactome 通路查询已实现，但旧版全局富集历史仍为未迁入；需要实际历史数据和归属/主键映射，不能改成虚构计数。
3. 五来源全量导入与业务对照、权威物种/规范编号、真实实验样例仍未完成。此项与当前小样本一致性通过分别记录。
4. 助手仅恢复最近一项任务，证候页仅展示最近八项；未增加完整历史管理新页面。网络药理工作台也没有在本轮扩写全历史浏览。
5. 真实模型、外部生物数据接口和生产部署继续暂缓；PCA、热图、GSEA、更广 RAG、R 交互网络不加入本轮。
