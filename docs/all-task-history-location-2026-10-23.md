# 已有模块的历史任务定位（2026-10-23）

## 本轮完成

本轮承接蛋白组学固定编号及网络历史图恢复，补齐其他已有任务的打开方式。复用原业务页面与结果组件，不增加研究算法、模型调用或资料导入，不修改布局 CSS。

| 已有任务类型 | 当前打开行为 |
| --- | --- |
| 证候文本分析 | 总览使用 `/analysis?textTask=<id>`；直接读取该任务，列表选择及新建结果同步网址，刷新不换成其他任务 |
| 医案分析 | 总览使用 `/cases?caseTask=<id>`；读取任务及对应医案，自动展开该医案的分析，候选只取该任务的记录 |
| 图表任务 | 使用登录后的 `/tasks/<id>` 查看该图本身，显示保存状态、预览及原工件下载；不会跳到最新蛋白组学分析 |
| Reactome / STRING 子任务 | 同样从 `/tasks/<id>` 查看原已保存结果，复用原结果/导出组件；不重新查询科学接口、不自动绘图 |
| 已有本地主任务 | 蛋白组学、助手、目录/疾病检索、本地网络主任务继续进入原工作台，并带明确任务编号 |

`/tasks/<id>` 是已有记录的定位入口，没有新增侧栏模块。主任务在该入口读取并核对后进入原页面；子任务保留自己的编号。未知类型不会猜成网络药理，缺少父任务外键也不会凭参数创建来源跳转。

指定编号必须是正安全整数；不存在、无权限或类型不符时显示错误，重试仍读原编号，不回退最新任务。切换网址的首轮渲染不展示旧文本/医案结果，迟到恢复、轮询、创建及下载响应不能覆盖新选择。排队/运行只查询原任务；失败、取消如实保留，不自动重发分析。

图表预览核对任务编号、图类型、参数与结果中的父编号、持久父外键（如有）及输入哈希（如有）；下载仅接受本站固定工件路径。历史缺少持久父外键但保存参数/结果父编号有效一致时，可以展示该图本身，同时明确未保存父关联、不推断父任务。HTML/PDF 只提供下载，不嵌入执行。

## 医案接口与正文边界

原 `/api/v1/research/cases/<id>/analysis/` 只读取最新任务，本轮新增可选只读参数 `task_id`。先沿用当前医案的账号权限检查，再按任务编号、该医案及 `case_link` 类型精确筛选；非法参数统一 400，不存在/其他医案/其他类型统一 404。无参数保持读取最新任务的原行为。归档历史可读；候选刷新和审核后仍读取所选任务。

页面的医案正文仍来自**当前医案记录**，不是本轮新建的历史正文快照。任务结果、候选、输入哈希属于指定历史任务；正文变化沿用 `stale` 提示及确认限制。不能将当前正文误称为当时正文，也没有为历史任务补造候选或重算结果。

没有新增数据库模型、migration 或后台执行逻辑；API 已正常重启加载新增只读参数，worker 不需要因本轮视图改动重启。

## 继续保留的待办

本轮没有处理整个 worker/主机消失后的自动维护、外部同步发布窗口或孤儿文件清理；现有显式维护命令仍有效。真实实验、权威物种/编号、候选医案来源/脱敏/跨表关系、旧 Reactome 全局历史及正式生产部署仍按原范围待验收。旧损坏记录缺少来源信息时，保留明确失败，不自动修写历史。
