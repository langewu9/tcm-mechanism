# 医案库与科研助手联通验收

日期：2026-10-28

## 交付范围

医案模块已接入本地网站，提供参考医案检索、分类筛选、分页、原文与来源版本查看，并可将选中的参考记录带入科研助手。参考医案库使用独立只读 SQLite 数据库，不改写平台原有业务数据库。

## 页面与数据流

- `/cases`：参考医案库与“我的医案”分开；参考库支持关键词、分类筛选、分页、记录详情、结构化字段、原文及来源版本核对。
- 从参考医案详情可将所选记录带入 `/assistant`。助手保存问题、所选记录和检索到的引用快照，结果保留记录编号及版本信息。
- 参考医案也接入个人医案分析的检索上下文；个人医案任务使用提交时冻结的参考库版本。原有个人医案归属、授权、人工审核和证据核验流程继续生效。
- 参考库检索为本地关键词匹配与排序，不使用向量嵌入，也不会把演示数据混入实验结论。

## 验收记录

- 页面核对：四类数量、分类筛选、分页、关键词结果、无结果状态、原文及出处展开、所选记录带入助手。
- 助手验证：无模型配置时可完成本地检索、保留选中的参考记录并返回来源；未调用生成式模型。
- 自动化测试：容器镜像内 Django 相关测试 34 项通过；前端生产构建通过；`test:research`、`test:r`、`test:api` 通过。
- 部署：Docker API、任务 worker、R 分析 worker 均健康。
- 数据核对：部署前后原业务库知识实体数均为 126,311、用户数均为 1；未执行原业务表迁移、重置或重新灌库。参考语料库已有独立备份。

## 使用边界

当前运行环境未配置可用的本机或内网生成模型，因此“生成式回答”功能未启用；界面只提供真实的本地检索结果，不伪造模型回答。参考医案中的结构化抽取状态按原数据保留，未人工核验的信息不会标记为已审核。生成式模型接通前，不能把本次结果描述为模型推理或临床建议。
