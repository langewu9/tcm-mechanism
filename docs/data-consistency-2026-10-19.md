## 重跑方式

在仓库根目录执行。第一步使用桌面依赖提供的 Python（含 pandas/openpyxl）；第二步使用项目 Django 虚拟环境。原件和生成 JSON 都在忽略目录，不进 Git。

```sh
<bundled-python> tools/audit_legacy_consistency.py extract \
  python_app/var/legacy-inputs/tcmsp全部数据.xlsx --rows 100 \
  --output python_app/var/legacy-source-extracted-audit.json

python_app/.venv/bin/python tools/audit_legacy_consistency.py compare \
  python_app/var/legacy-source-extracted-audit.json --source-id 5 --task-id 11 --http \
  --output python_app/var/legacy-consistency-audit.json

python_app/.venv/bin/python tools/smoke_mapping_consistency.py
```

`--http` 要求本地预览服务和已有验收管理员凭据；最后一条命令会新增并保留合成数据集和分析任务。审计 compare 不创建分析任务。报告必须是独立 JSON，不能覆盖原输入或写入来源数据库目录。

## 跨库标识、物种和同名歧义保护

后续静态审查发现，原 UniProt 同步仅凭本地 `metadata.symbol` 相同就关联人类 accession，没有排除未知/其他物种、停用来源或 `unverified_symbol`；预览用原字符串比较、应用用大小写和空白归一，可能给出不同的关联结果。重跑同步还可能将已有 accession 改绑到新出现的同名记录。

现有同步业务已修补，没有另建映射业务模块：

- 预览与应用共用 `uniprot-human-identity-2`。活跃且启用来源的基因/蛋白实体，仅在 `organism` 明确记录为 `Homo sapiens` 或 `Homo sapiens (Human)`、符号未标为 `name_only`/`unverified_symbol` 且候选唯一时，参与现有符号关联。这里依据的是本地已经记录的断言，不代表重新完成了生物学鉴定；不从名称推测物种。
- 物种未知、其他物种、未核实符号或多个合格同名实体保持独立；UniProt 目录可建立自身带版本的实体，不据此自动改造旧记录。不同 accession 按原有设计可以归属同一基因实体，未把基因实体改成蛋白亚型模型。
- 已有 accession 的有效归属优先于新增同名候选。若已有归属的物种/符号不兼容、实体停用或来源停用，整次应用停止，不转移编号；预留 `uniprot-gene:*`/`uniprot:*` 身份也不能覆盖其他来源的实体。真实命名变更须先人工核对，并重新预览。
- 来源文件校验之外增加本地身份计划 SHA-256。预览后物种、符号、来源启用状态、候选歧义或既有编号归属改变时，应用拒绝。旧预览没有新依据，须重新预览。相关行在应用事务中加锁；生产 PostgreSQL 并发尚未实测，不以 SQLite 回归宣称并发验收通过。
- 关联标识保留人类 `taxonId=9606`；缺少该元数据的旧标识会计入待更新。TSV 物种字段采用完整值校验，不接受仅有相同开头的其他字符串。
- 原 `/admin/sources` 同步历史增加物种未知/其他物种/未核实候选、已有编号归属与冲突统计。分类可重叠。冲突和旧预览在页面及应用 API 均阻止提交；API 沿用 `VALIDATION_ERROR`、详情和请求 ID 格式，worker 再复核最新计划。

只读盘点工具 `tools/audit_catalogue_identities.py --source-id 5` 对本地 SQLite 连接启用 `PRAGMA query_only=ON`，得到 17 个活跃旧库蛋白实体：17 个 `name_only`、17 个物种空缺、17 个没有启用的外部标识，本来源内规范化名称重复组为 0。结果保存在忽略目录 `python_app/var/catalogue-identity-source-5.json`；该数字不是跨库匹配完成或没有生物学歧义的证明。

身份规则使用隔离测试数据库和合成 UniProt 快照验证，未从外部获取真实目录，也未把测试快照写入本地知识库。回归覆盖物种缺失/错误、未核实符号、停用来源、同名歧义、基因实体复用、大小写与空白一致性、保留已有编号、归属冲突/保留 ID 碰撞不改数据、预览失效、旧预览、API 队列前保护、标识物种元数据更新及重复应用。最终 369 项后端测试通过，UniProt 测试文件从 6 项增至 22 项；前端来源管理回归与交付构建、OpenAPI 和迁移漂移检查通过。后端全套测试使用独立 Redis 测试库 15，避免清理预览缓存；首次受限环境不能连接 Redis 的运行不计通过。

真实 HTTP 检查已重启后的服务，确认管理员来源列表可读、研究者访问管理来源被拒绝、更新后的组件可加载、历史任务仍按所有者隔离。没有新建实际 UniProt 同步记录，没有进行本轮浏览器点击验收。报告为 `python_app/var/identity-local-http-check.json`。
