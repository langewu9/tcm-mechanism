源码中统计图组件和主任务 R 图库组件处在同一父节点下，都使用 `key={result.taskId}`。这处冲突在 `df197a2` 的父提交也存在；本轮增加历史读取状态更新后可实际观察到重复节点，不能仅凭源码中只有一处组件调用就判定界面无问题。

修补范围限定为让统计区与各用途 R 图库的 key 不冲突，继续保留任务编号参与 key 以隔离任务切换；没有调整计算、数据、组件内容或 CSS。
