# 标准靶点主表与核验说明

2026-10-27。当前版本仅核验 UniProt 审校人类参考目录覆盖的编号，不把未知物种名称记录自动认定为人类。

## 数据结构与比较口径

- `TargetMaster` 是物种限定的标准靶点主表：`entrez:9606:3569` 为基因，`uniprot:9606:P05231` 为蛋白。基因与蛋白主键分开；只有参考目录明确提供唯一基因对应时，蛋白记录才参加基因层级比较。
- `TargetIdentityMapping` 保存来源实体到标准靶点的版本化映射、输入指纹、匹配方法、候选和理由。状态为已核验、待核验、歧义、冲突或未映射。
- 原 `KnowledgeEntity` 的整数主键、UUID、stable_id、物种、关系外键和来源行不被改写。原始实体交集继续保留，页面另列标准基因交集、标准蛋白交集和待核验共同候选。
- 名称只生成候选；未知物种保持未知。多义功能名称和被截断的多候选集合不进入“唯一基因对应的共同候选”统计，更不进入已核验交集。
- 人类目录之外的编号不自动判错、退休或改成人类。需增加相应物种/历史编号参考版本后再核验。数据库 `validated` 标记、预测分数以及实验有效性也不因身份映射而升级。

## 发布与更新

在 `python_app` 中运行：

```powershell
python -m apps.sources.connectors.target_reference var/target-reference
python manage.py resolve_target_identities var/target-reference/<version>.manifest.json
python manage.py resolve_target_identities var/target-reference/<version>.manifest.json --apply
```

下载只使用固定公开目录查询，不提交本地靶点列表。程序校验文件 SHA-256、字段、总记录数、物种及参考版本；映射版本还包含来源实体输入指纹。默认仅预览；应用时新增标准键和映射，并在同一事务内切换已发布版本指针。失败不发布半成品；重复执行同一输入版本不重复插入。

应用迁移或映射前备份当前数据库。定时同步仍保持关闭。不得把运行数据库、用户工作簿或私有参考缓存提交到公开仓库。

## 查询、追溯与验收

- 当前参考版本由专用数据源 `target-reference-uniprot-human` 的发布指针确定；禁用该参考源时停止使用其映射。
- 查询时重新比较输入指纹。来源实体或有效标准编号改变后，旧映射不再用于当前比较，必须重新构建版本。
- 网络药理任务把映射发布ID和比较规则版本写入快照，关联参考 `SourceRelease`；历史任务不随新映射静默变化。
- 管理员可在“接入监测”的主表状态和 Django 管理后台查看映射。只读API：`GET /api/v1/admin/target-identities/?status=candidate&search=IL6&page=1`，每页50条，普通用户不可访问。
- 新增表的迁移为 `0026_target_identity_overlay`。第一批使用 UniProt `2026_03` 的20,431条审校人类蛋白，建立39,684个基因/蛋白标准键；63,923条来源靶点记录中24,316条按明确编号核验。17,490条为唯一名称候选、159条有歧义、21,958条未映射。上述为记录数，不代表不同生物学靶点数量。

新增TCMSP工作簿含 `Entry`，但已发现跨物种及错误注释。仅凭该列存在或其编号格式正确不能批量升级映射；需按文件版本和来源靶点ID复核，并隔离名称/物种冲突。原文件的网络连接度表不能当作新增互作证据。
